# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

Security and privacy are core pillars of FileFlow.

If you discover a security vulnerability in FileFlow:

1. **Do not create a public GitHub issue.**
2. Report the vulnerability privately via GitHub Security Advisories or by emailing the project maintainer.
3. Provide details including:
   - Type of vulnerability (e.g. path traversal, memory leak, improper permission retention)
   - Steps to reproduce
   - Potential impact

We will review, acknowledge, and resolve confirmed vulnerabilities promptly.
